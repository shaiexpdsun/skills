# Exemplos

## Relatório HTML

Pedido: “faz um relatório…”, “html-report”, “status das tracks”, “compara X e Y”.

1. Ler `tokens.html`, copiar o bloco `<style>` (canal B: preto + cinza frio, sem azul).
2. Shell: `.app` → topbar (opcional) + rail + main + aside + statusbar (opcional).
3. Factos reais. Busca se a tabela tiver >8 linhas.
4. Gravar em `./reports/<nome>.html` (ou pasta que o utilizador indicar).
5. No chat: path + 5–10 linhas.
